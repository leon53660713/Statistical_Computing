# 統計計算專案 (Statistical Computing Project)
本儲存庫包含了在台北大學統計系就讀期間，於「統計計算」課程中所完成的系列實作練習 <br>
本專案利用 Python 程式語言解決統計學中的運算問題，並透過視覺化手段深化對統計理論的理解 <br>

# 內容總覽
[HW1] 基礎繪圖 (Basic Drawing) <br>
目標：掌握 Python 的基本繪圖指令，探索 11 種不同函數的特性 <br>
核心內容：觀察函數的局部/全域極值、實數根分布、漸近線以及函數定義域 <br>

[HW2] 廣播機制與矩陣運算 (Broadcasting) <br>
目標：學習使用迴圈與矩陣運算進行高效計算 <br>
核心內容：透過 3 種不同的圖形實作，理解 NumPy 的廣播機制 (Broadcasting) 如何加速統計運算 <br>

[HW3] 機率分配與圖形視覺化 (Probability Distributions) <br>
目標：繪製並觀察常見連續型與離散型機率分配的長相 <br>
核心內容： <br>
* 連續型：常態 (Normal)、卡方 (Chi-square)、T、Beta、F 分配的 PDF 繪圖 <br>
* 離散型：Poisson 分配的 PMF (stem 圖) 與 CDF (stairs 圖) <br>

參數探索：調整參數以觀察分配形狀的動態變化 <br>

[HW4] 蒙地卡羅實驗與 J-B 檢定 (Monte Carlo & J-B Test) <br>
目標：以蒙地卡羅實驗驗證 Jarque-Bera (J-B) 檢定統計量 <br>
核心內容：透過模擬實驗比較 J-B 檢定與其他常態性檢定方法的檢定力 (Power) 與型一錯誤 (Type I Error) <br>

[HW5] 單變量函數的根與最小值 (Finding Roots & Minima) <br>
目標：實作數值分析演算法尋找單變量函數的根與極值 <br>
核心內容：包括二分法、牛頓法等演算法的實作與視覺化呈現 <br>

[HW6] 多變量函數參數估計與模擬 (Multivariate Optimization) <br>
目標：在限制條件下進行多變量函數的參數估計 <br>
核心內容： <br>
* 混合常態分配：進行混合常態模型的參數估計 <br>
* 限制式最佳化：解決具備限制條件的最大值問題，並利用 等高線圖 (Contour Plot) 與 3D 圖 進行視覺化分析 <br>
